# 🚀 Antigravity Telegram Bot (Remote Control & AI Assistant)

Персональный Telegram-бот для удаленного управления ноутбуком **THUNDEROBOT 911S** со смартфона с интеграцией **Google Gemini 2.5 Flash / Antigravity**.

---

## 📱 Возможности

1. **Мониторинг ноутбука в реальном времени:**
   - `/status` (или кнопка `📊 Статус ПК`) — нагрузка на процессор (CPU), оперативная память (RAM), свободное место на дисках C: и D:, уровень заряда батареи, статус питания и время работы с момента включения.
2. **Снимки экрана (Live Screenshot):**
   - `/screen` (или кнопка `📸 Скриншот`) — мгновенный захват текущего экрана монитора и отправка снимка прямо в Telegram в высоком качестве.
3. **Удаленный PowerShell терминал:**
   - `/cmd <команда>` — выполнение любых команд терминала на ноутбуке с телефона. Если вывод слишком длинный, бот автоматически отправит его текстовым файлом.
4. **Управление процессами:**
   - `/ps` — топ ресурсоемких приложений по потреблению оперативной памяти.
   - `/kill <PID или имя>` — принудительное завершение зависшей программы (например, `/kill chrome.exe`).
5. **Безопасность и блокировка:**
   - `/lock` (или кнопка `🔒 Заблокировать`) — мгновенная блокировка экрана Windows (Win + L).
   - `/sleep` — перевод ноутбука в спящий режим.
   - **Приватный режим:** бот слушает команды только от одного владельца. При первом запуске бот предлагает привязать твой Telegram-аккаунт в один клик. Посторонние люди получить доступ к компьютеру не смогут.
6. **AI Ассистент Gemini (Antigravity):**
   - Любое текстовое сообщение без слэша отправляется в Gemini AI с памятью контекста беседы.
   - **Голосовые сообщения:** отправь боту голосовое сообщение — Gemini расшифрует твою речь и даст развернутый ответ!
   - `/clear` — сброс контекста беседы с Gemini.
   - `/setkey <api_key>` — быстрая привязка или смена ключа Gemini API прямо из чата.

## ⚡ Быстрый старт за 1 минуту

### Шаг 1. Получить Bot Token в Telegram
1. Открой Telegram и найди бота [@BotFather](https://t.me/BotFather).
2. Напиши команду `/newbot`.
3. Придумай имя (например: `My Laptop Antigravity`) и юзернейм (например: `my_antigravity_pc_bot`).
4. Скопируй полученный токен (вида `782348234:AAElk2_...`).

### Шаг 2. Получить бесплатный Gemini API Key
1. Перейди на [Google AI Studio](https://aistudio.google.com).
2. Нажми **"Get API key"** -> **"Create API key"**.
3. Скопируй ключ.

### Шаг 3. Запуск
- На рабочем столе дважды кликни на ярлык:
  `Запустить_Антигравити_Бота.bat`
- При первом запуске скрипт сам спросит Bot Token и Gemini API Key и сохранит их в `config.json`.
- Открой созданного бота в Telegram со своего смартфона и нажми `/start`!
- Нажми кнопку **"🔐 Привязать мой аккаунт как владельца"** — и ноутбук полностью в твоем распоряжении!
